# Scroll-Driven Hero Section Animation

Live: https://sampada620.github.io/hero-scroll/

## Tech Stack
React (Vite), Tailwind CSS, GSAP (ScrollTrigger)

## Features
- Staggered headline and stats reveal on load
- Scroll-linked car animation using GSAP ScrollTrigger (scrub + pin)
- Transform-only animations for smooth performance
- Responsive layout

## Run locally
npm install
npm run dev
